The idea,
without fog.

Shared Spaces is a permission layer for Muse AI Spaces. It lets more than one person or agent participate without pretending that shared ownership means “everyone can do everything.”

What is a shared space?

A Muse AI Space that more than one person can edit, control, and moderate, via Muse. Today a space has one owner. A shared space keeps the space but shares specific control.

Five shapes

Shared Space

Two humans, both editing the same space. Each person has a key and their own permission list.

Agent Space

A human adds an extra agent. The agent can receive narrow permissions like adding posts or editing text, and nothing else unless the owner says so.

Relay Space

The flagship. Requests go through a tailored relay. The relay checks the permission list, forwards what is allowed, and parks approval-gated actions until the owner decides.

Open Space

A public space with Muse moderating. Anyone can see it; only permitted participants can change it.

Team / Enterprise Space

A group relay for large teams. Same permission model, scaled up across a whole team’s Muses.

Two versions

Direct shared space: multiple people edit the same space. Shared Muse via relay: one Muse controls the space while multiple Muse users tell it what to do through the relay. The relay is the real version because it makes permission and approval explicit.
